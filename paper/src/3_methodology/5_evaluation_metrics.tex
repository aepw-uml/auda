\subsection{Evaluation}

In this study, the evaluation metrics for the imputation and temporal forecasting tasks include mean absolute error (MAE), root mean squared error (RMSE), the coefficient of determination (\(R^2\)), weighted absolute percentage error (WAPE), and symmetric mean absolute percentage error (sMAPE).
The formulas for these metrics are presented in Appendix~\ref{sec:appendix_b}.

Since the targets in these tasks are physical quantities, such as plastic waste generation measured in tonnes, WAPE is treated as the primary performance metric.
It is used for hyperparameter tuning in the imputation and temporal forecasting tasks.
Other metrics are reported for reference and to provide additional insights into model performance.

Some datasets in this study have very few data points (less than 10), and there are only two held-out data points for those experiments.
In this case the denominator of \(R^2\) is very small, and modest absolute errors can produce a large negative \(R^2\), making it less meaningful than other metrics.
For this reason, we do not report \(R^2\) for experiments with fewer than five test observations.

For each model and metric, let \(q_{r,m}\) denote the value of metric \(m\) obtained in run \(r\), where \(r=1,\ldots,R\).
We report the arithmetic mean across runs:
\[
	\bar{q}_m = \frac{1}{R}\sum_{r=1}^{R}q_{r,m}.
\]
All runs use the same dataset, model definitions, configured hyperparameter ranges, evaluation metrics, and workflow settings.
The run seed varies, so random operations, such as data partitioning and validation masking, may differ across runs.
