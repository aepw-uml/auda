\subsection{Data Migration to AUDA Analytical Database}

AUDA uses a script to migrate human-reviewed extracted records from PRISM into its analytical database through an Extract-Transform-Load (ETL) process. This migration stage reorganizes the records into an analytical schema in which all tables are keyed by location and year. During the migration, the script filters out records with null values and ensures that units are consistent across all data points. For records with the same key, the script only retains the most recent ones.

All analyses and experiments in this study use the AUDA analytical database snapshot dated March 4, 2025.
