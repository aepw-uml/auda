This study presented AUDA as a reproducible analytical workflow built from validated records in the PRISM data ecosystem. AUDA organizes heterogeneous plastic-waste, demographic, socioeconomic, waste-management, resin-consumption, and polymer-specific records into country-year datasets that can be used for modeling. Using this workflow, we evaluated correlation and feature-importance analysis, missing-value reconstruction, univariate temporal forecasting, pooled neural-network forecasting, and country-specific multivariate forecasting. The experiments show that sparse environmental data require careful modeling and interpretation: the best-performing method changes with the target variable, country, sample size, and trend shape.

The empirical results do not support a single universally superior model. SVR performs strongly in several settings, including the global plastics production forecasting task and multiple reconstruction tasks. At the same time, simple interpolation, smoothing, and statistical baselines remain competitive for short country-level series, where flexible models can overfit or become unstable. The multivariate experiments further show that pooled neural-network pretraining can help in some country-specific settings, such as Japan, but does not reliably dominate simpler models, as shown by the Slovenia result. These patterns are expected for plastic-waste data, where many countries and indicators have only a few observations and where reporting practices differ across sources.

The proposed selection-efficiency coefficient for the one-standard-error rule provides a practical way to control the trade-off between validation performance and model simplicity. In the reconstruction sensitivity study, \(c_{\mathrm{SE}} = 0.1\) frequently changed the selected hyperparameter configuration while adding only a small WAPE penalty. Larger tolerance values selected simpler configurations more aggressively, but with larger performance penalties. This suggests that modest standard-error tolerance can reduce hyperparameter-selection instability without materially degrading predictive accuracy, although the appropriate tolerance should still be checked for each modeling setting.

Several limitations remain. The AUDA analytical tables are built from verified records, but the underlying data are still sparse, noisy, and heterogeneous. Some evaluation splits contain only a few held-out observations, making metrics such as \(R^2\) unstable and making model rankings sensitive to small changes in the data. Percentage-based metrics also require care because target magnitudes vary widely across countries and indicators. In this study, WAPE is therefore treated as the primary metric, while MAPE and \(R^2\) are interpreted cautiously. The current driver-based forecasting tasks also do not explicitly include policy interventions, infrastructure investment, regulatory changes, or waste-management capacity, all of which may strongly affect future plastic-waste generation.

Future work should expand the set of validated country-year records, incorporate policy and waste-management covariates, quantify forecast uncertainty more explicitly, and test whether pooled or transfer-learning approaches can improve country-specific forecasts without masking local behavior. Overall, AUDA provides a foundation for reproducible plastic-waste modeling under realistic data constraints. The results indicate that reliable forecasting in this domain depends less on choosing a universally superior model and more on matching model complexity, validation strategy, and interpretation to the amount and quality of data available.
