\subsection{Experiment 3: Missing-Value Imputation}

% The AUDA analysis table is highly sparse due to substantial missing data across countries, regions, and years. Therefore, in Experiment 3, we impute the missing values in the \texttt{YearTRC (Japan)} and \texttt{YearTRC (US)} datasets.
The AUDA analysis table is highly sparse due to substantial missing data across countries, regions, and years. Therefore, in Experiment 3, we impute the missing values in the \texttt{YearTRC (Japan)} and \texttt{YearTRC (United States)} datasets.

The experiment evaluates reconstruction of artificially masked observed values. It compares simple interpolation baselines with statistical and machine-learning imputation models. Baseline models include linear interpolation, moving average interpolation, and cubic spline interpolation, which are commonly used for filling gaps in time series. Statistical and machine learning models include ridge regression, GPR, SVR, and Theil--Sen regression.

Because both datasets have only 9 data points, each run uses only two held-out observations for testing. In this case, the denominator of \(R^2\) is very small, and modest absolute errors can produce a large negative \(R^2\). For this reason, the \(R^2\) metric is not very meaningful here, and we do not report it.

Table~\ref{tab:imputation_japan_trc} shows that, on the \texttt{YearTRC (Japan)} imputation task, Cubic Spline Interpolation has the lowest MAE, RMSE, and WAPE among the evaluated methods, and SVR has the lowest WAPE (1.59\%) among the machine learning models, compared with 1.48\% for cubic spline interpolation and 1.59\% for linear interpolation. On the \texttt{YearTRC (United States)} task (Table~\ref{tab:imputation_united_states_trc}), Theil--Sen Regression has the lowest WAPE (1.17\%), while SVR remains competitive among the machine learning models at 1.22\%. Given that each task holds out only 2 test observations, these rankings should be interpreted as indicative rather than definitive.

Figure~\ref{fig:imputation_plots} shows representative fitted trajectories from the imputation experiments. The \texttt{YearTRC (Japan)} series exhibits a more nonlinear trend than the \texttt{YearTRC (United States)} series. On these two-point hold-outs, SVR appears to fit both the linear and the relatively nonlinear trends reasonably well, although this observation is illustrative rather than conclusive.

Because the datasets are small, the imputation results are sensitive to noise and randomness. Therefore, we cannot draw strong conclusions about the relative performance of the evaluated methods. However, the results suggest that, among machine learning models, SVR is relatively competitive for imputing missing values in time series data when the dataset is small.
