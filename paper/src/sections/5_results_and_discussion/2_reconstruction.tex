\subsection{Experiment 3: Reconstruction}

Table~\ref{tab:reconstruction_japan} shows that all machine learning methods did not perform better than moving average interpolation for \texttt{YearPPC (Japan)}. Among all machine learning models, ridge regression has the highest WAPE and SVR has the highest \(R^2\) among all machine learning models.
