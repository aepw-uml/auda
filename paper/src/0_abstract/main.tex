\abstract{
	% Okay
	Plastic waste planning depends on country-level data that are often sparse, irregular, and heterogeneous across sources. This study presents AUDA, an analytical workflow built from human-reviewed extracted records in the PRISM data ecosystem, for constructing modeling datasets and evaluating imputation and forecasting methods under these constraints. The AUDA analytical database contains more than 28{,}000 human-reviewed extracted records across 195 countries and regions, covering demographic, socioeconomic, waste-management, resin-consumption, and polymer-specific indicators. Using these records, we evaluate correlation and feature-importance analysis, missing-value imputation, univariate temporal forecasting, and pooled neural-network prediction. The evaluation compares interpolation and time-series baselines, statistical models, ridge regression, Gaussian process regression, support vector regression, and multilayer perceptrons. We also introduce a standard-error tolerance coefficient for the one-standard-error (1-SE) hyperparameter-selection rule, which permits explicit adjustment of the validation-error threshold used to select simpler configurations. Across the experiments, no single model is uniformly best. Support vector regression performs strongly in several imputation and global forecasting settings, simple statistical baselines remain competitive for short country-level time series, and pooled neural-network prediction on heterogeneous records remains an exploratory case study. Weighted absolute percentage error (WAPE) is used as the primary metric because target magnitudes vary widely across countries and indicators. Overall, AUDA provides a reproducible foundation for evaluating plastic-waste models and shows that reliable forecasting in this domain requires matching model complexity and validation strategy to the amount and quality of available data.
}
