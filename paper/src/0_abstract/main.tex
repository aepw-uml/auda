\abstract{
	Plastic waste planning depends on country-level data that are often sparse, irregular, and heterogeneous across sources. This study presents AUDA, an analytical workflow built from validated records in the PRISM data ecosystem, for constructing modeling datasets and benchmarking reconstruction and forecasting methods under these realistic data constraints. The AUDA analytical database contains more than 28{,}000 verified records across 195 countries and regions, covering demographic, socioeconomic, waste-management, resin-consumption, and polymer-specific indicators. Using these records, we evaluate correlation and feature-importance analysis, missing-value reconstruction, univariate temporal forecasting, pooled neural-network forecasting, and country-specific multivariate forecasting. The benchmark compares interpolation and time-series baselines, statistical models, ridge regression, Gaussian process regression, support vector regression, random forests, and multilayer perceptrons. We also introduce a selection-efficiency coefficient for the one-standard-error hyperparameter-selection rule, allowing the tolerance for validation-error uncertainty to be adjusted when selecting simpler configurations. Across the experiments, no single model is uniformly best. Support vector regression performs strongly in several reconstruction and global forecasting settings, simple statistical baselines remain competitive for short country-level time series, and neural-network forecasting benefits from pooled pretraining in some multivariate settings but remains sensitive to data heterogeneity and small holdout sets. Weighted absolute percentage error is used as the primary metric because target magnitudes vary widely across countries and indicators, while \texorpdfstring{\(R^2\)}{R2} is interpreted cautiously for very small test sets. Overall, AUDA provides a reproducible foundation for evaluating plastic-waste models and shows that reliable forecasting in this domain requires matching model complexity and validation strategy to the amount and quality of available data.
}
